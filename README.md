## 在线做题（Web 应用）

本仓库还带了一个可以部署在家庭 NAS 上的刷题应用，支持：

- **考试模式**：选年份 / 地区 / 试卷，整卷倒计时，答题卡、标记、交卷后逐题解析；
- **练习模式**：按套卷或按 22 个二级题型抽题，选完立即判题，答案自动去重；
- **自定义练习**：可选多个模块混合抽题，数量/顺序/是否立即判题都可调；
- **错题本**：答错自动收录，连续答对 3 次自动标记已掌握；
- **错因解析**：官方解析如果逐项写了 A/B/C/D 的对错原因，会拆成「错因解析」，直接看你选错的那一项；
- **统计**：个人正确率、模块 / 题型分布、最近 14 天活跃、家庭成员总量对比；
- **搜索**：按题干或解析关键词找题，找到后可直接开一道单题练习；
- **疑问标记**：做题时标记答案/解析/图片问题，集中在我的疑问里查看；
- **家庭成员**：右上角切换 / 添加 / 改名 / 删除，每个人的考试、练习和错题本独立，题库共享；
- 手机 / 电脑自适应，支持深色模式，无登录认证，适合家庭内网。

入口：

- 应用说明与本地开发：[`app/README.md`](app/README.md)
- 飞牛 NAS 部署：[`DEPLOY-飞牛NAS.md`](DEPLOY-飞牛NAS.md)
- 快速本地运行：`cd app && npm install && npm run dev:server`，另开终端 `npm run dev:web`

## 怎么用

1. **用 Obsidian 打开**：把本文件夹「打开文件夹作为仓库」，链接与图片可直接点开（推荐）
2. **用 VS Code / Typora 等**：打开任意 `.md`，用预览模式看（图片是相对路径，一样能显示）
3. **纯文本查看**：内容都能读，只是图片位置会显示路径

见 [`蒸馏方法参考.md`](蒸馏方法参考.md) —— 我们把用过的拆书方法论（RIA-TV++）、十二条踩坑经验、
